## Common Issues & Solutions

### ❌ Issue: Form doesn't submit
**Solution:** 
- Clear browser cache: Ctrl+Shift+Del
- Refresh page: F5
- Check console for JavaScript errors: F12

### ❌ Issue: Data doesn't appear in verify_evaluation_saving.php
**Solution:**
- Wait 2-3 seconds (database latency)
- Refresh verify tool: F5
- Check database connection in `check_database_status.php`

### ❌ Issue: CAR results page shows no data
**Solution:**
- Make sure you selected "view all" mode
- Check URL: `/comparative_assessment_results.php?view=all`
- Verify applicant saved with verify tool first

### ❌ Issue: Report generates but shows blank data
**Solution:**
- Some export formats need document reader (PDF needs reader, Excel needs viewer)
- Try HTML first to verify data is there
- Try different browser
