## What Each Column Shows

The detailed CAR table includes:

| Column | What It Shows |
|--------|---------------|
| Rank | Position ranking (1=highest, 2=second highest) |
| NAME | Applicant's full name |
| APPLICATION CODE | Unique application ID (SAMPLE-001, etc.) |
| Education | Education score |
| Training | Training hours score |
| Experience | Years of experience score |
| Performance | Performance rating |
| Outstanding Accomplishments | Achievements score |
| Application of Education | How education is applied |
| Application of L&D | Learning & development application |
| Potential | Growth potential |
| Total | Combined weighted score |
| Remarks | Additional notes |
| Background Yes/No | Background check status |
| For Appointment | Appointment recommendation |
| For Probation | Probation status |

## Troubleshooting

### "No applicants found"
- Make sure you clicked the Insert button first
- Try refreshing the page (F5)
- Check that the Success message appeared

### "Position dropdown is empty"
- Sample data might not have inserted
- Go back and click Insert button again
- Make sure you see the ✅ Success message

### "I don't see the format from the image"
- Make sure you selected "View by Position" (Step 3)
- The "View All" mode shows a different layout
- Select a position and you'll see the detailed format

### Still having issues?
- Go to: insert_sample_applicants.php
- Click the Insert button again (it will reset the data)
- Try viewing results again
