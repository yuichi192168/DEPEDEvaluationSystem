🗄️ Database Schema

A new table comparative_assessment_results has been added with the following columns:

Column Name Type Purpose
position_id INT Link to position
applicant_id INT Link to applicant
application_code VARCHAR Application identifier (e.g., ICT-2026-001)
*_score columns (8 total) DECIMAL Individual scoring for each criterion
total_score DECIMAL Sum of all scores
rank INT Auto-calculated ranking
background_yes/no BOOLEAN Background check status
for_appointment BOOLEAN Appointment recommendation
for_probation BOOLEAN Probation recommendation

🔧 Integration Steps

Step 1: Run Migration

Visit: http://yoursite/setup/migrate_car.php

This will create the necessary database table. You can also load sample data from there.

Step 2: Access the Display Page

Navigate to: http://yoursite/comparative_assessment_results.php

Select a position from the dropdown to view ranked results.

Step 3: Save Results via API

Use the RESTful API at api/save_comparative_assessment.php to save assessment results.

Step 4: Update Your Forms

Add CAR fields to your evaluation form to enable automatic saving to the comparative assessment database.

💻 API Example

Save Single Result

curl -X POST http://yoursite/api/save_comparative_assessment.php \ -H "Content-Type: application/json" \ -d '{ "position_id": 1, "applicant_id": 5, "scores": { "application_code": "ICT-2026-001", "education": 8.50, "training": 12.00, "experience": 15.00, "performance": 13.80, "outstanding_accomplishments": 0, "application_of_education": 0, "application_of_ld": 0, "potential": 13.80, "total_score": 63.10, "background_yes": true, "background_no": false, "for_appointment": true, "for_probation": false }, "remarks": "Highly qualified", "assessment_date": "2026-01-22" }'
