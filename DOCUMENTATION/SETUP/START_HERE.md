# ⭐ START HERE - 2 Minute Quick Start

Get the system running in just 2 minutes with these 3 simple steps!

---

## 🎯 3 Simple Steps

### ✅ Step 1: Insert Sample Data (30 seconds)

**Open this URL in your browser:**
```
http://localhost/DEPEDEvaluationSystem/insert_sample_applicants.php
```

**Then click the green button:**
```
"➕ Insert 4 Sample Applicants"
```

**You should see:**
```
✅ Sample Data Inserted Successfully
4 applicants have been inserted
```

---

### ✅ Step 2: View All Results (30 seconds)

**Open this URL in your browser:**
```
http://localhost/DEPEDEvaluationSystem/comparative_assessment_results.php?view=all
```

**You should see:**
```
COMPARATIVE ASSESSMENT RESULT - Annex I

Position: Information and Communications Technology
├─ Rank 1: Maria Santos - Score: 9.38
└─ Rank 2: Juan Dela Cruz - Score: 8.73

Position: [Another Position]
├─ Rank 1: Ana Reyes - Score: 8.08
└─ Rank 2: Carlos Mendoza - Score: 7.25
```

---

### ✅ Step 3: View by Position (30 seconds)

**Open this URL in your browser:**
```
http://localhost/DEPEDEvaluationSystem/comparative_assessment_results.php
```

**Then:**
1. Select a position from the dropdown
2. Click "View Results" or the position name

**You should see:**
```
Position: Information and Communications Technology
Plantilla Item Number: n/a
Date of Final Deliberation: January 22, 2026

[Detailed CAR table with all scores and rankings]
```

- [ ] Sample data inserted successfully (✅ message shown)

- [ ] Rankings show 1, 2 per position
- [ ] Position dropdown has options
- [ ] Can select a position
- [ ] Detailed CAR format appears
- [ ] All columns displayed (NAME, CODE, Education, etc.)
