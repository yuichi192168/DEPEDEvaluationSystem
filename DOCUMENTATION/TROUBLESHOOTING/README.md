## 🆘 Emergency: Something Broke!

Follow these steps:

1. **FIRST:** Refresh the page (F5 or Ctrl+R)
2. **SECOND:** Close and reopen your browser
3. **THIRD:** Check [TROUBLESHOOTING.md - Quick Fixes](./TROUBLESHOOTING.md#quick-fixes)
4. **FOURTH:** Check your specific error below:

**Error Starting with:**
- "Error" or "Failed" → [DATABASE_FIXES.md](./DATABASE_FIXES.md)
- "404" → [TROUBLESHOOTING.md - 404 Errors](./TROUBLESHOOTING.md#404-errors)
- "500" → [TROUBLESHOOTING.md - 500 Errors](./TROUBLESHOOTING.md#500-errors)
- "Database" → [DATABASE_FIXES.md - Connection Issues](./DATABASE_FIXES.md#connection-issues)
- Something else → [FAQ.md - General Questions](./FAQ.md#general-questions)

## ✅ Verification Checklist

Before assuming something is broken, verify:

- [ ] PHP is running (XAMPP/server started)
- [ ] MySQL/MariaDB is running (XAMPP/server started)
- [ ] Browser is up to date (Chrome, Firefox, Safari, Edge)
- [ ] URL is correct (http://localhost/DEPEDEvaluationSystem/...)
- [ ] Sample data has been inserted (see [../../SETUP/START_HERE.md](../../SETUP/START_HERE.md))
- [ ] You refreshed the page (Ctrl+F5 for full refresh)
- [ ] No browser extensions are blocking content
- [ ] JavaScript is enabled
- [ ] You cleared browser cache if needed

If all verified and still having issues, check the specific troubleshooting guide.
