How to Use
  • 1. Enter Applicant Name
    Type the applicant's name in the "Applicant Name" field. The calculator will suggest previously saved names as you type.
  • 2. Add Subjects
    Click "Add Subject" or use Ctrl+Shift+A to add subject cards. For each subject, select a grade (1.00-3.00) and units (1-8).
  • 3. Use Grade Shortcuts
    Press number keys 1-9 to quickly set grades: 1=1.00, 2=1.25, 3=1.50, 4=1.75, 5=2.00, 6=2.25, 7=2.50, 8=2.75, 9=3.00.
  • 4. Quick Actions
    Use Bulk Add for multiple subjects, Copy Last to duplicate the previous subject, or Quick Units buttons to apply the same units to all.
  • 5. Calculate & Save
    Click "Calculate GWA" (Ctrl+Enter) to compute the weighted average. Add optional notes, then click "Save as New Record" to store the calculation.
  • 6. Manage Records
    Pin favorites with the star icon, batch select and delete multiple records, or compare 2-3 applicants side-by-side. View stats for your records.
Calculation Formula
  • Step 1: List all subjects with grades, units, and numerical values
  • Step 2: Multiply each grade by its unit weight (e.g., 1.50 × 3 units = 4.50)
  • Step 3: Sum all weighted grades from all subjects
  • Step 4: Add up the total number of units taken
  • Step 5: Divide total weighted grades by total units = GWA
